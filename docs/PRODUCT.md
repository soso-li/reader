# Reader 产品说明

Reader 是一个面向个人使用的自托管信息阅读器。它把持续到达的 RSS / Atom 内容整理为可阅读、可搜索、可追踪的事件流，同时保留每篇原文作为可核验的来源证据。

## 阅读与整理

- 按时间浏览完整内容流，并按来源、媒体类型、未读状态和搜索条件筛选。
- 抽取正文并保留安全的富文本结构、图片和音频入口。
- 将相似报道聚合为 Event，同时允许查看每个来源及其原文。
- 支持看过、未读、稍后阅读、星标和明确偏好等阅读状态。

## 摘要与合成

- 为单篇内容生成摘要和翻译。
- 基于固定证据快照生成带引用的多来源合成稿。
- 生成日、周、月报告，并保留报告引用的历史证据版本。
- 本地模型与 OpenAI-compatible HTTP API 由用户明确选择，不静默切换 provider。

## 来源管理与隐私

- 通过设置页添加、预览、分类、暂停和删除订阅源。
- 新来源默认未分类且禁止外发。
- 私密来源只允许本地模型处理；公开来源仍需单独允许外部生成。
- 外部抓取拒绝私网、loopback、带凭据 URL、超量响应和主动 SVG 内容。

## 自托管

Reader 由 Next.js Web、FastAPI API、PostgreSQL / pgvector、Redis Queue 和后台 worker 组成。仓库根目录的 Compose 配置提供通用自托管入口；具体配置见 [README](../README.md)。
